# 心绘非遗｜本次改造说明

本分支在原有 HTML / CSS / JavaScript / Canvas 项目上迭代，没有推倒重写。

## 本次改造
- 非遗工艺入口收敛为剪纸、扎染两种。
- AI 二创提示词以视觉模型识别到的原画元素、构图和用户补充为锚点，禁止擅自新增/替换主体。
- 增加用户确认区：可补充需保留的主体细节，并选择作品希望承载的感受。
- 本地兜底不再把圆形、斜线等抽象形式强行解释成龙凤、牡丹等具体物体。
- 增加文化工艺资料入口，并补充项目介绍中的创新点、评价维度与伦理边界。
- 对扎染数字预览与真实扎结、防染、浸染工序作出区分。

## 技术边界
当前 CogView-3-Flash 使用文本生成图像，不是真正的图生图模型。提示词、原笔迹叠加可以增强关联性，但不能承诺像素级保真。若要严格保留结构，后续应接入支持参考图/图生图、ControlNet 或分割掩码的模型，并进行真实样本评估。

## 测试建议
1. 分别绘制“有明确主体的画”（如太阳、小屋、树）与抽象线条。
2. 检查视觉识别元素、用户校对文本是否进入生成说明。
3. 对比剪纸、扎染结果，确认主体数量、位置、方向未被任意替换。
4. 打印剪纸图样做连桥与细节可剪性测试；用布料样片验证扎染防染位置。
5. 收集原画关联度、情绪认同、文化可理解性、用户控制感、工艺可制作性五维反馈。

## 安全与伦理
心理图鉴只用于艺术表达与自我觉察，不用于疾病诊断或人格定性。正式上线前请确认第三方模型 API Key 不暴露在前端，并对用户绘画上传、保存和删除机制作清晰告知。
